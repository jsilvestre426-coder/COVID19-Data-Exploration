# COVID-19 Data Exploration in SQL

## Project Overview

This project explores global COVID-19 data using SQL to uncover trends in infection rates, death rates, and vaccination progress across countries and continents. It was completed as a guided project based on Alex the Analyst’s YouTube SQL portfolio project tutorial.

The analysis focuses on using SQL to clean, explore, and prepare COVID-19 data for further visualization and insight generation.

## Objectives

The main goals of this project were to:

- Analyze COVID-19 cases, deaths, and vaccination data
- Compare infection rates across countries
- Calculate death percentages by location and date
- Identify countries with the highest infection rates relative to population
- Examine continent-level death counts
- Track vaccination progress over time
- Practice SQL techniques commonly used in data analysis

## Dataset

The dataset used in this project contains global COVID-19 data, including:

- Total cases
- New cases
- Total deaths
- New deaths
- Population
- Vaccination counts
- Location and continent information
- Dates of reported COVID-19 statistics

The data was sourced from publicly available COVID-19 datasets, commonly provided by Our World in Data.

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft Excel / CSV files

## SQL Skills Demonstrated

This project demonstrates the use of several SQL concepts, including:

- `SELECT` statements
- `WHERE` filtering
- `ORDER BY`
- Aggregate functions
- `GROUP BY`
- `JOIN`
- Common Table Expressions (CTEs)
- Temporary tables
- Window functions
- Rolling calculations
- Creating views for visualization
